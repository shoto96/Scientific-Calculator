Calculadora Científica

Calculadora científica moderna e responsiva feita com Bootstrap 5.3, Font Awesome e JavaScript ES6+, com diversos recursos matemáticos e interface avançada.

✨ Funcionalidades
Básico: operações (+, -, ×, ÷, %), parênteses, decimal, limpar e backspace
Científico: trigonometria, logaritmos, potências, raiz, fatorial, π, e
Extras: memória (MS/MR) e modo RAD/DEG
Algoritmos: Shunting Yard, Fibonacci, fatorial, bases numéricas, equação 2º grau, primalidade, MDC/MMC
Interface: tema dark/light, design moderno (glassmorphism), responsivo, histórico clicável, suporte a teclado
📁 Estrutura
index.html
css/style.css
js/ (algoritmos, lógica, UI, inicialização)
assets/favicon.svg
🚀 Uso

Abra o index.html no navegador.
Funciona 100% no cliente (sem servidor).
